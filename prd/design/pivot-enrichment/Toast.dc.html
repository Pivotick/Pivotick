The consumer's gate is allowed to land less than the analyst chose (D9). Saying so is not an error message — it is the difference between a hook and a lie.

Library gap this design depends on — and it is bigger than "no action button" Today's toast is removed on a hard 4,000 ms timer, with no hover-pause, no dismiss control, and showNotification returns void (UIManager.ts:1096-1106). Four seconds is roughly the time it takes to read "Ingested 12 nodes, 14 edges", never mind decide to undo it — and with no handle there is nothing to flip to "Undone — Redo". The minimal extension is therefore four things, not one:
notify(level, title, message?, { action?: { label: string, onClick: () => void }, timeout?: number, // 12_000 when an action is present dismissible?: boolean, // the ✕ }): NotificationHandle // .update(...) / .dismiss()
C9 Everything above is drawn against this shape. If it is not built, the undo affordance has to move — most likely into the triage pane — and auto-ingest pivots lose their only undo surface entirely.
